# OC-Project11-PoC

Preuve de concept du Projet 11 basée sur une architecture microservices.

## Composants

- geocoding-service
- routing-service
- hospital-service
- recommendation-service
- bed-reservation-service
- frontend

## Objectif

Démontrer la faisabilité de l'architecture définie dans les livrables du projet et valider les principes d'industrialisation, d'intégration continue et de communication entre services.
