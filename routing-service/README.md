# routing-service

Microservice responsable du calcul des distances et des temps de trajet.

## Responsabilité

Calculer les distances réelles et les temps de déplacement entre deux points géographiques.

## Entrée

- Coordonnées d'origine
- Coordonnées de destination

## Sortie

- Distance
- Temps de trajet

## Consommateur principal

- recommendation-service
